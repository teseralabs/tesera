# contributing

tesera is an early experimental project

## setup

requires Node.js 20 or newer

```bash
npm install
npm test
```

`npm test` compiles the TypeScript and runs the tests

`npm run build` compiles without running the tests

run the CLI with:

```bash
npm run tesera -- --help
```

## changes

talk about a protocol, wire-format, or security change before a large implementation

changes to the protocol or wire format can affect compatibility with other tesera implementations and versions

a behavior change needs a test when a test can show that behavior
